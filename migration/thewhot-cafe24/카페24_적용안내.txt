THE WHOT → CAFE24 이전 준비 패키지
수집·작성일: 2026-10-30 (Asia/Seoul)

1. 준비 결과
- 공개 URL 105건 수집: 주요 페이지·별칭·약관 진입 주소·게시판 목록 및 게시글 포함.
- 공개 이미지 289개와 참고 CSS 81개 다운로드 성공. 이미지에는 썸네일 및 코드에서 확인한 원본 파일이 포함됨.
- 13개 주요 브랜드 페이지 + 한살림 협업 게시글 1개를 카페24 스마트디자인용 HTML로 변환.
- 실제 페이지에서 사용하는 이미지 132개를 /web/upload/thewhot/images/ 경로로 매핑.
- 아임웹 로그인·주문·분석·추적·게시판 전용 스크립트는 카페24 적용 파일에서 제외.
- Vimeo 영상 1개는 기존 임베드 주소 유지. 영상 원본 파일은 다운로드하지 않음.
- 문의 폼의 필드와 선택지는 reports/forms.json에 보존.
- PC 1440px / 모바일 390px, 14페이지 × 2가지 화면에서 이미지 로딩·가로 넘침 검증 완료. 상세 결과 reports/preview-validation.json.

2. 파일 구조
cafe24/skin/: 스마트디자인 편집 대상 HTML/CSS. 카페24 스킨 ZIP 자동등록 형식이 아니라 파일 배치용 패키지.
cafe24/web/upload/thewhot/images/: 카페24 파일 업로더로 올릴 이미지.
source/: 원본 HTML, 페이지별 인라인 CSS, robots/sitemap, 참고 스타일. 보관용이며 배포하지 않음.
content/: 페이지별 추출 문구·위젯 정보·정리된 본문. 이미지 속 문구는 이미지에 보존되며 OCR/편집 가능한 원고는 별도 작업.
reports/: 출처·체크섬·페이지/이미지 매핑·문의 항목·상품 연결 초안·게시글 검토·검증 결과.
preview/: 카페24 런타임을 대신한 로컬 콘텐츠 미리보기. 헤더는 검토용이며 실제 카페24 선택 스킨에서 최종 조정 필요.
review/: PC/모바일 화면 검수 이미지.
tools/: 재수집·변환·미리보기 도구.

3. 카페24 적용 순서
① 관리자에서 적용 대상 스킨을 복사하여 작업본으로 사용. 현재 운영 스킨을 바로 덮어쓰지 않음.
② 파일 업로더에서 /web/upload/thewhot/images/ 경로에 images 안의 파일 업로드. 업로드 결과 URL이 패키지 경로와 같은지 확인.
③ 스마트디자인에서 /css/whot-brand.css 및 /brand/*.html 파일 추가.
④ 각 페이지의 @layout(/layout/basic/layout.html), @css(/css/whot-brand.css) 지시문 유지. 대상 스킨에 layout.html이 있는지 확인하고 다르면 실제 레이아웃으로 변경.
⑤ 홈페이지 index.html은 작업본 스킨에만 적용. 기존 쇼핑몰 콘텐츠와 충돌하는지 확인.
⑥ 기존 헤더 메뉴를 reports/route-map.json에 맞춰 연결. layout/basic/whot-navigation.html은 메뉴 참고 조각이며 자동 연결되지 않음. 헤더 CSS·모바일 메뉴는 대상 스킨에 맞춰 마감.
⑦ 대상 스킨의 #contents 폭·여백이 이미지 중심 페이지를 제한하는지 확인하고 필요한 경우 해당 브랜드 페이지에만 폭 조정. 공통 쇼핑몰 CSS를 무차별 변경하지 않음.
⑧ 로컬 검증과 별도로 카페24 작업본에서 이미지·메뉴·상품·로그인·문의·영상·모바일 전체 검수.
⑨ 상품/문의/약관/도메인·URL 처리를 확정한 후 공개 스킨과 도메인을 전환. 본 패키지는 업로드·배포하지 않은 상태.

4. 별도 연결이 필요한 기능
- 상품: 상품 소개 이미지 26개를 reports/product-mapping-draft.json에 정리. 실제 상품 개수와 동일하다고 간주하지 말 것. 상품명·가격·옵션·재고·판매 자격은 확정하지 않았으며 상품번호/가격은 비워둠. 카페24 상품 등록 후 상세 링크 매핑 필요. 관리자 엑셀 업로드 서식을 임의로 만들지 않음.
- 문의: Design by Us / Design Your Own은 현재 연락처 안내로 대체. 기존 아임웹 폼 제출 주소는 사용하지 않음. 수집 항목으로 카페24 게시판 또는 별도 폼 구축 필요. 필수 여부·개인정보 동의 검수 필요.
- 회원/주문: 카페24 기본 모듈과 관리자 설정으로 연결. 소셜 로그인·PG·성인인증 신청은 아직 진행하지 않음.
- NEWS: 원문 게시글 63개 중 한살림 협업 글 1개만 이전용 페이지에 반영. 나머지 62개는 브랜드와 무관한 광고성 게시글로 판단해 검토 목록에 분리. 원본은 보존했고 원 사이트 글은 삭제하지 않음. 카페24 게시판으로 관리하려면 본문 이관 및 게시판 번호 확정 필요.
- 이용약관/개인정보: 공개 팝업 원문을 별도 보관. 원문에 ‘사이트명’/‘회사명’ 등 미완성 문구가 있어 그대로 게시하지 말 것. 카페24 실제 사업자·수집항목·처리업체에 맞춰 확정해야 함.
- 영상: https://vimeo.com/1072020123. 새 도메인의 임베드 허용 여부·계정 소유권은 미확인. 검증 중 외부 네트워크는 차단했으므로 영상 실제 재생은 카페24 작업본에서 확인.
- 폰트: 원본 CSS는 참고 자료로만 보관. 카페24용 CSS는 시스템 글꼴 사용. 이미지에 포함된 글꼴은 원래 이미지 그대로 보존. 원본 웹폰트 적용이 필요하면 사용권과 호스팅 경로 확인.
- 슬라이드/갤러리: 내용·순서와 PC/모바일 갤러리 열 수 보존. 메인 배너는 가로 스크롤 방식의 기본 동작이며 원본 자동재생·전환 효과는 최종 스킨에서 조정할 대상.

5. 수집 범위와 한계
공개 메뉴·사이트맵·게시판 페이지 연결로 확인 가능한 자료 기준. 비공개 자료, 관리자 DB, 회원·주문·문의 응답, 원본 디자인 편집 파일은 포함하지 않음. 외부 SNS·지도는 링크로 기록하고 해당 계정 전체를 수집하지 않음. 이미지 URL에 thumbnail이 있어도 공개 파일 원본 바이트 그대로 저장했고 SHA-256을 기록함. 원본 크기 이상 확대하거나 문구를 새로 생성하지 않음.
기존 디자인과 콘텐츠는 보존하되 현재 변환본은 이전 작업용 초안임. 실제 카페24 템플릿 엔진·선택 스킨 검증과 완전한 픽셀 일치는 아직 확인하지 않음.
