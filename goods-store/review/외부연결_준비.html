외부 서비스 연결 준비 · 실제 연결 보류

항목준비 구조연결 전 확인
Firebase개발·운영 프로젝트 분리, 사용자 식별자 연결, 이미지 저장 경로·권한 분리프로젝트 소유자, 리전, 요금제, 보존·삭제 정책. 현재 로컬 인증과 자동 연동하지 않음.
소셜로그인제공자 인증 → 서버 검증 → 내부 회원 연결 → 세션 발급. 성공·실패·연결 해제 화면 분리.제공자별 앱과 동의항목, 콜백 도메인, 계정 중복 처리. 이메일만으로 기존 계정 자동 병합 금지.
PG비주류 굿즈 전용. 결제 요청·승인·실패·취소·환불 이벤트 인터페이스 설계. 서버 금액 대조·중복 방지.사업자 계약·수수료·지원 결제수단·테스트키. 현재 주문은 DEMO 상태만 사용.
배포개발/검토/운영 환경 분리. 빌드 → 테스트 → 백업 → 배포 → 상태 점검 → 복구.호스팅·도메인·HTTPS·비밀키 저장소·DB 백업. 개발용 관리자 입구 제거, 운영 DB 신규 구성.
유료 서비스사용량 상한·알림·월 예산을 확정한 후 신청Firebase, DB, 이미지 저장, 호스팅, PG 조건 모두 미확정. 신청·과금 없음.

구성 파일: src/integrations/config.ts. 모든 연결 enabled=false. 실제 외부 서비스 기능이 완성된 상태가 아닌 연결 설계와 설정 자리만 준비한 상태입니다.
